# 💜 Трип-свайп — Сингапур и Корея

«Тиндер мест» для поездки вдвоём: свайпаем места, ловим мэтчи, смотрим их на карте, собираем план по дням и оставляем заметки.

**Сайт:** откройте ссылку GitHub Pages этого репозитория (Settings → Pages).

## Как пользоваться

1. Первая открывает сайт → «Создать нашу комнату» → появляется код вида `K7PM-2QXA`.
2. Вторая открывает сайт → «Войти по коду» (или просто открывает ссылку из раздела «Ещё → Комната»).
3. Свайпайте: вправо — хочу, влево — нет, вверх — обязательно. Общие лайки = мэтчи 💞.
4. «Карта» — все места и мэтчи на карте, «План» — дни 4–14 марта и голосование за рейс, «Ещё» — заметки, чек-лист, советы, экспорт.

## Предложения и музыка

- 💡 **Предложить место** (кнопка в шапке или «＋» на карте): вставьте ссылку из Google/Apple Карт или координаты, добавьте название, заметку и фото. У подруги место окажется первым в свайпах, а у автора оно сразу отмечено «хочу».
- 🎵 **Фоновая музыка**: песни добавляются с устройства и хранятся только в его памяти (IndexedDB), в репозиторий и в интернет они не попадают. Плейлист играет по кругу, кнопка 🔊/🔇 в шапке выключает звук.

## Что внутри

- 333 места: Сингапур, Сеул, поездки по Корее (Сувон, Нами, Пусан, Кёнджу, Чонджу, Каннын, Чеджу) и аэропорты пересадок в Китае.
- Экспорт в KML (Google My Maps → Google Карты), GPX (Organic Maps / Maps.me офлайн), CSV и ссылки на Google, Apple, Naver и Kakao.
- Советы: въезд, eSIM, деньги, переводчики, карты, транспорт, погода, концерты, фразы.

## Как устроена синхронизация

Своего сервера нет. Данные комнаты шифруются кодом комнаты (AES-GCM) и хранятся на нескольких публичных nostr-релеях, а также в памяти каждого телефона. Каждое устройство публикует всё, что знает, поэтому данные восстанавливаются с любого из них. В «Ещё → Экспорт» можно скачать резервную копию.

## Разработка

Обычный статический сайт без сборки: `index.html`, `css/`, `js/`. База мест — `js/data/*.js`, маршрут и рейсы — `js/trip.js`, советы — `js/tips.js`.

Локально: `python -m http.server 8765` и открыть http://localhost:8765.
